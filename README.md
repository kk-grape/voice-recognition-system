# 智能语音识别系统

基于 Spring Cloud Alibaba 微服务架构与 Vue 3 前端的智能语音处理平台，集成阿里云 NLS 语音识别、通义千问大模型、百度翻译与支付宝支付，覆盖「录音文件转写」「实时语音识别」「语音翻译合成」「AI 会议纪要」等核心场景。

---

## 一、项目简介

本系统面向会议记录、语音转写、多语言沟通等实际需求，采用前后端分离 + 微服务架构：

- **录音文件转写**：上传音频/视频，调用阿里云 NLS 异步转写接口，自动生成带时间轴的字幕，按音频时长计费并通过支付宝沙箱完成支付。
- **实时语音识别**：通过 WebSocket 与后端建立双向流，实时返回识别结果，支持多语种识别、百度翻译互译、TTS 语音朗读。
- **AI 助手 / 会议纪要**：接入通义千问（DashScope），对实时识别出的会议字幕自动生成结构化纪要（要点、行动项、决策、关键词），并支持对话式追问修改。
- **文件格式转换**：基于 FFmpeg 的 WebSocket 实时转码服务。
- **管理后台**：会员管理、订单管理、识别记录查询、数据统计。

## 五、核心业务流程

### 1. 录音文件转写（付费流程）

```
用户上传音频
  → 后端计算时长与费用（0.2 元/分钟）
  → 生成待支付订单（order-service）
  → 支付宝沙箱支付
  → 支付回调成功后，提交阿里云 NLS 转写任务
  → NLS 异步转写完成，回调后端 /filetrans/callback
  → 后端解析结果，写入字幕表（filetrans_subtitle）
  → 用户查看 / 导出 SRT 字幕
```

### 2. 实时语音识别与翻译

```
浏览器采集麦克风音频（PCM 16kHz）
  → WebSocket 连接 /ws/asr
  → 流式上传音频帧
  → realtime-asr-service 转发至阿里云 NLS
  → 识别结果实时返回前端
  → 按需调用百度翻译 API 翻译
  → 调用 TTS 合成目标语言语音并播放
  → 会话结束后，字幕持久化到 asr_session / asr_subtitle
```

### 3. AI 会议纪要

```
实时识别结束
  → ai-assistant-service 拉取该会话全部字幕
  → 调用 qwen-long 生成结构化纪要（要点/行动项/决策/关键词）
  → 保存到 ai_meeting_summary
  → 用户可通过对话（qwen-plus）追问、修改纪要
```

## 六、快速启动

详细步骤参见 [部署说明.md](./部署说明.md)，最小启动顺序：

1. 启动中间件：MySQL → Redis → Nacos（命名空间 `music`）→ Sentinel → Seata
2. 执行 `music/sql/` 下对应脚本，创建 7 个 `kk-*` 数据库
3. 后端根目录执行 `mvn clean package -DskipTests`，按顺序启动各服务 jar
4. 前端分别进入 `music-web` 和 `music-admin`，执行 `npm install` 后 `npm run dev`
5. 访问：
   - 用户端：http://localhost:3000
   - 管理后台：http://localhost:3001
   - 网关：http://localhost:18000

## 八、配置说明

1. **外部服务密钥**：在各服务的 `application.yml` 中配置你自己的阿里云 AccessKey、支付宝密钥、百度翻译 Key、DashScope API Key，相关配置项均已预留。
2. **公网回调**：阿里云 NLS 与支付宝支付需要公网可访问的回调地址，本地开发可使用 ngrok / frp 等内网穿透工具，并将生成的地址填入对应配置项。
3. **本地文件目录**：音频输出目录在 `audio-service`、`realtime-asr-service` 的配置中指定，按实际环境修改即可。
4. **数据库**：本项目采用每服务独立数据库，初始化时创建全部 7 个 `kk-*` 库。
